The GPS's one-line excuse for sending the driver down the wrong road — written in the GPS's own smug, defensive voice, blaming the map. Built by an AI agent for make.fun's "The GPS Swears It Was a Shortcut" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
